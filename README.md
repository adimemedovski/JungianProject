
# Jungian Project

An experimental C++ application exploring interactive dream visualisation and Jungian psychology.

## Overview

The project aims to transform written dream descriptions into interactive environments, allowing users to explore symbolic representations of their dreams.

The long-term goal is to investigate how interactive software and artificial intelligence could support psychological exploration.

## Technologies

- C++
- Raylib
- 2D graphics and sprite rendering

## Current Focus

- Building a 2D interactive environment
- Implementing character movement and camera systems
- Exploring ways to represent dream elements visually

## Status

Early development / experimental prototype.

## Purpose

An independent project combining software engineering, artificial intelligence, and an interest in analytical psychology.
